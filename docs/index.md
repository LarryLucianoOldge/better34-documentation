# Welcome

This simple site provides a human-readable Rule 34 API documentation as we want to give developers a clear and neatly formatted documentation for developing project revolving around Rule 34.

!!! danger "Disclaimer"

    This is not the official API documentation. In case of broken features or irrelevancy, please refer to the <a href="https://api.rule34.xxx/" target="_blank">official documentation</a>.

## Purpose

Don't get me wrong. The official docs is already decent. It is concise and straight to the point. But for me as a beginner developer, I find it lacks of detailed informations such as response method, response example, errors, etc. which might drives people out of confusion. I also think that the docs could be re-formatted so that it feels less cluttered and gives the clarity for the readers.
